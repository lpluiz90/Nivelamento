# Nivelamento em IA

Trilha de nivelamento em Inteligência Artificial — Escola de Comunicações.
Dos fundamentos de LLM e RAG à leitura e extração de dados de documentos.

Cada aula é um arquivo HTML autocontido (sem build, sem dependência de
rede): abre offline em qualquer navegador.

## Aulas

0. [A Cadeia do Dado](aulas/aula-0-cadeia-do-dado.html) — abre a trilha: o mapa das 16 UDs do curso
1. [RAG e Extração Estruturada](aulas/aula-1-rag-extracao-estruturada.html)
2. [Tokens](aulas/aula-2-tokens.html)
3. [Vibe Coding](aulas/aula-3-vibecoding.html)
4. [JSON](aulas/aula-4-json.html)
5. [Markdown](aulas/aula-5-markdown.html)

## Estrutura

```
index.html   — página inicial (hub das aulas)
assets/      — imagens compartilhadas
aulas/       — uma aula por arquivo HTML
```
